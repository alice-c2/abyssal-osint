Build it into your stack.

Automate investigations, enrich your own data, and wire Abyssal into your tooling with a typed SDK, a CLI, and a fully documented REST API.

Typed SDK

The official @abyssalosint/sdk wraps every endpoint with full TypeScript types and handles auth for you.

REST API

Every tool in the dashboard is available over a clean, documented HTTP API with an OpenAPI specification.

Scoped API keys

Mint keys with per-feature permissions and expirations straight from your dashboard.

Typed SDK

Drop the SDK into any Node or Bun project and get full TypeScript autocomplete for every search.

discord.ts 
import { Abyssal } from '@abyssalosint/sdk';

const abyssal = new Abyssal({
  apiKey: process.env.ABYSSAL_API_KEY,
});

const result = await abyssal.socials.searchDiscord({
  query: '123456789012345678',
});

console.log(result.data);

// → {
//   userId: '123456789012345678',
//   username: 'username',
//   displayName: 'Display Name',
//   pfp: 'https://cdn.discordapp.com/avatars/...',
// }

Install

$ npm install @abyssalosint/sdk $ pnpm add @abyssalosint/sdk $ bun add @abyssalosint/sdk

Run searches from the terminal, shell scripts, and CI pipelines with the @abyssalosint/cli package.
